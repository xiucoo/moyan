# 墨言（Moyan）

面向 macOS 的轻量 Markdown 笔记应用。笔记以本机文件夹中的 `.md` 文件存储，可选 iCloud Drive 多设备同步。

## 特色功能

### 知识库

以真实文件夹与 Markdown 文件组织知识，不是封闭数据库。

- 默认「知识库」文件夹，可自建分类、标签筛选、全文搜索
- 三栏布局：文件夹 / 列表或画廊 / 编辑器
- 语法高亮、工具栏格式化、编辑 / 预览 / 分栏
- 本机 `~/Documents/墨言`，或迁移到 **iCloud Drive/墨言** 同步
- 可在 Finder 中直接增删改 `.md`，应用会扫描并重建索引

### 工作日志：连续工作 + 子任务

专为日更工作流设计的「工作日志」文件夹。

- **连续工作编辑**：进入日志时若今日尚无覆盖篇，可「继续昨日」——标题从 `2026-08-04` 延展为 `2026-08-04～05`，正文与子文件全部保留，无需复制粘贴
- **也可新建今日**：从空白日期篇重新开始
- 列表按今天 / 昨天 / 月份分区；日期为标题，`> 简介` 为副标题
- **子任务**：在任务行右键「新建子任务」，生成关联子笔记，正文出现可点击的 `📎子文件` 标记，一键跳转与返回

### AI

基于 Cursor SDK 的笔记助手（需配置 API Key）。

- **提问**：选中正文或直接提问，答复可插入当前笔记
- **分析**：对单篇笔记或整个文件夹执行——总结要点、提取待办、润色改写、风险与问题、自定义提问
- 默认模型 grok-4.5；设置中填写 Cursor API Key，并可一键安装本地桥接依赖

## 其它能力

- 文字颜色 / 背景色、正文查找替换（`⌘F` / `⌘⌥F`）
- 导出当前笔记或文件夹为 PDF（`⌘E` / `⌘⇧E`）
- 链接并预览 WPS 表格 / 文档（`.xlsx` / `.docx`）
- 外观：跟随系统 / 浅色 / 深色；强调色可选叶绿、青石、雾蓝、藤紫、琥珀

## 要求

- macOS 14+
- Xcode 16+
- （可选）WPS，用于编辑链接的办公文件
- （可选）Cursor API Key，用于 AI

## 运行

```bash
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
open Moyan.xcodeproj
```

在 Xcode 中选择 **My Mac**，按 `⌘R` 运行。也可先 `⌘B` 编译，再双击 `运行墨言.command` 启动 Debug 包。

## 笔记库位置

| 模式 | 路径 |
|------|------|
| 本机 Documents（默认） | `~/Documents/墨言` |
| iCloud Drive | `iCloud Drive/墨言` |

### 切换到 iCloud

1. 系统设置中登录 Apple ID，并开启 **iCloud 云盘**
2. 墨言 → **设置** → 将「笔记库位置」切换为 **iCloud Drive**
3. 选择「迁移并切换」后，笔记会出现在 Finder 的 `iCloud Drive/墨言`
4. 其它 Mac 安装墨言并选择同一位置即可同步

也可在设置中「按磁盘重建索引」，以文件夹与 `.md` 文件为准重建列表。

### 从妙言迁移

将笔记复制到「文稿/墨言」，然后在设置中点击「按磁盘重建索引」。根目录下的 `.md` 会归入「未分类」。

## 常用快捷键

| 操作 | 快捷键 |
|------|--------|
| 新建笔记 | `⌘N` |
| 新建文件夹 | `⌘⇧N` |
| 刷新当前文件夹 | `⌘R` |
| 重命名所选文件夹 | `⌘⇧R` |
| 打开所选文件夹位置 | `⌘⇧O` |
| 查找 | `⌘F` |
| 查找与替换 | `⌘⌥F` |
| 查找下一个 / 上一个 | `⌘G` / `⌘⇧G` |
| 导出当前笔记为 PDF | `⌘E` |
| 导出当前文件夹为 PDF | `⌘⇧E` |
| 重启应用 | `⌘⌥R` |

## 项目结构

```
Moyan/
├── Moyan/                 # 应用源码（SwiftUI + AppKit）
│   ├── AI/                # Cursor AI 服务
│   ├── Models/            # 设置与笔记模型
│   ├── Store/             # 笔记库与编辑桥接
│   ├── Utilities/         # Markdown / PDF / WPS 等
│   └── Views/             # 界面
├── Moyan.xcodeproj/
├── Tools/cursor-bridge/   # Cursor SDK 桥接脚本
└── 运行墨言.command       # 启动已编译 Debug 包
```
